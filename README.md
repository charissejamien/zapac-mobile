# 📱 ZAPAC

A modern React Native application built with **Expo**, **NativeWind (Tailwind CSS)**, and **TypeScript**.

---

### 🚀 Getting Started

Follow these steps to get the development environment running on your local machine.

#### 1. Prerequisites
Ensure you have the following installed on your system:
*   **Node.js** (LTS version recommended) — `node -v`
*   **npm** — `npm -v`
*   **Expo Go** app — Download on [iOS](https://apps.apple.com/app/expo-go/id982107779) or [Android](https://play.google.com/store/apps/details?id=host.exp.exponent) for mobile testing.

#### 2. Installation
Clone the repository and install the necessary dependencies:

```bash
# Clone the repository
git clone https://github.com/your-username/zapac-mobile.git

# Navigate into the project directory
cd zapac-mobile

# Install dependencies
npm install

```

#### 3. Development
Start the Expo development server:
```bash
npx expo start
```

#### 4. Testing on Mobile
Once the server is running:
1. Open the **Expo Go** app on your smartphone.
2. Scan the **QR Code** displayed in your terminal.
3. The app will bundle and open automatically!
